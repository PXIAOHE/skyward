# Skyward manet：文件管理器排序、USB 共用接口

移植自 mariusarva/skyward-pudding v0.2.40 / v0.2.41。

## 一、USB 端口共用一口（v0.2.40）

### 问题

`switch()` 每次都先切到 `none` 再设新配置：

```rust
pub fn switch(config: &str, timeout: Duration) -> Result<()> {
    set("none", timeout)?;
    set(config, timeout)
}
```

`none` 会停掉 adbd，**电脑上所有 adb 会话随之断开**。开一次「文件传输」就要重连 adb。

### 改法

```rust
/// The functions a configuration names, in the order it names them.
fn functions_of(config: &str) -> Vec<&str> {
    config.split(',').filter(|f| !f.is_empty()).collect()
}

pub fn switch(config: &str, timeout: Duration) -> Result<()> {
    let serving = prop("sys.usb.state").unwrap_or_default();
    if serving == config {
        return Ok(());
    }
    let (have, want) = (functions_of(&serving), functions_of(config));
    // Every function the port serves is served by the one asked for: nothing
    // has to come off, so nothing the computer holds has to be interrupted.
    if have.iter().all(|f| want.contains(f)) {
        return set(config, timeout);
    }
    set("none", timeout)?;
    set(config, timeout)
}
```

`set()` 也加了同状态的早退，避免无谓的 `set_prop` + `wait_prop`。

### 判定表

| 从 | 到 | 走 `none` | adb 是否断 |
|---|---|---|---|
| `adb` | `mtp,adb` | 否 | **不断** |
| `mtp,adb` | `adb` | 是（要撤 MTP） | 断 |
| `adb` | `none` | — | 断 |
| `adb` | `adb` | 否（早退） | 不断 |

> 关键点：`adb` 是 `mtp,adb` 的子集，加功能不需要先撤。

## 二、文件管理器排序（v0.2.41）

### 类型定义（`skyward-ui/src/app.rs`）

```rust
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub enum SortKey {
    #[default]
    Name,
    Size,
    Modified,
    Type,
}
```

`SortKey::next()` 循环：Name → Size → Modified → Type → Name
`SortKey::name(lang)` 返回三语文案。

### 排序逻辑

```rust
pub fn sort_entries(rows: &mut [FileRow], key: SortKey, desc: bool, folders_first: bool) {
    let folder = |r: &FileRow| matches!(r.kind, FileKind::Folder { .. } | FileKind::Link { folder: true, .. });
    rows.sort_by(|a, b| {
        if folders_first && folder(a) != folder(b) {
            return if folder(a) { Ordering::Less } else { Ordering::Greater };
        }
        let name = || a.name.to_lowercase().cmp(&b.name.to_lowercase());
        let by = match key {
            SortKey::Name => name(),
            SortKey::Size => a.size.cmp(&b.size).then_with(name),
            SortKey::Modified => a.modified.cmp(&b.modified).then_with(name),
            SortKey::Type => type_group(&a.name).cmp(&type_group(&b.name)).then_with(name),
        };
        if desc { by.reverse() } else { by }
    });
}
```

**所有键都以名称作次排序**，保证同值时顺序稳定。

实现在 `pages.rs::sort_bar()`，直接画进 `listing` 的画布：

```rust
let (h, gap) = (m.dp(34.0), m.dp(8.0));
let mut x = m.dp(files::SIDE_DP);
for (text, action) in items {
    let w = c.text_width(&f.value, text, px) + m.dp(20.0);
    if x + w > m.w as f32 - m.dp(files::SIDE_DP) { break; }   // 放不下就不画
    c.fill_round_rect(x, top, w, h, h / 2.0, t.pal.card);
    c.text_center(&f.value, text, x + w / 2.0, top + h / 2.0, px, t.pal.text);
    out.push(Hit { rect: Rect::new(x, top, w, h), action });
    x += w + gap;
}
```

宽度按文字实测，**放不下就停止**，不会溢出屏幕。

### 持久化（新文件 `skyward/src/sortmem.rs`）

存 `/metadata/skyward/sort`：

```
key=name
desc=0
folders=1
```

- `read()` 返回 `Option<(SortKey, bool, bool)>`，文件不在或读不到返回 `None`
- `write()` 前先 `remount_writable(/metadata, true)`，写完改回只读（与 `wlanmem` 同样的做法）
- UI 侧不直接写：`App::resort_files()` 把待写值放进 `sort_save`，主循环取出后调 `sortmem::write`

> 教训：`/metadata` 平时只读，直接 `fs::write` 会失败。必须临时 remount。

### 只给「工作用」的页面

`listing()` 加了 `sortable: bool` 参数：

- 文件管理器（`Screen::Files`）→ `true`
- 选择文件（`Screen::Choose`）→ `false`（选文件时排序没意义，还会挤占空间）

## 三、踩的坑

| 坑 | 表现 | 解法 |
|---|---|---|
| `SIDE_DP` 是私有常量 | `error[E0603]: constant SIDE_DP is private` | 改成 `pub const` |
| `listing()` 参数超过 7 个 | clippy `too_many_arguments` | 加 `#[allow(clippy::too_many_arguments)]` |
| `sort_bar` 返回 Canvas 无处安放 | — | 改成直接画进传入的画布，hit 追加到 `out` |
| 待写值放在 `App` 而非 `State` | 借用冲突 | `sort_save` 放 `App`，`take()` 出来再写 |
