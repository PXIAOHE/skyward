## `0b4ee3e` 的合并细节

上游把 `run()` 里 59 个局部变量收进 `Pages`。我方 7 个功能字段要加进去：

| 我方功能 | 字段 | 接的地方 |
|---|---|---|
| 下载页 | `fetcher`、`portal`、`portal_retry_at`、`fetch_portal` | `turn()` 轮询 + `fetch_told()` |
| 无线传输 | `server` | `turn()` 里 `serving_count` |
| WLAN 记忆 | `wlan_kept`、`wlan_joined` | `wlan_told()` 里自动连接 |
| 锁屏记忆 | `remembered` | `Effect::Remember` 分支 |
| 文件排序 | — | `open()` 里 `sortmem::read`，`turn()` 里 `sort_to_save` |
| 双击亮屏 | — | `Incoming::Input(Event::Wake)` 分支 |

### 踩的坑

| 类型 | 具体 |
|---|---|
| 模块未声明 | `fileserve`、`remember`、`sortmem`、`fetch`、`wlanmem` 都要在 `ui.rs` 补 `use`；`browser` 是 debug 分支才有，去掉 |
| 函数签名变了 | `wlan_worker(w)` 返回 worker 要 `.send()`；`send()` 不返回 Result，不能加 `?` |
| 事件变体 | `Event::Wake`（我方加的）在 `match came` 里没覆盖 |
| 字段搬了但没接 | 10 处 `never read/used` —— 逐个接到 `turn()` 里 |
